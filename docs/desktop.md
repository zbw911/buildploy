# 桌面版支持

Buildploy Studio 提供 Windows 桌面工作台，把 AI 协作与本地 Git 工程、编辑器和原生开发工具连接起来。适合已经拥有项目源码，或需要结合本机 Android、微信开发者工具推进应用开发的场景。

[文档目录](README.md) · [功能全景](features.md) · [企业级支持](enterprise.md)

## 在自己的电脑上连接工程与工具

| 能力 | 可以怎样使用 | 带来的价值 |
| --- | --- | --- |
| 接入本地 Git 工程 | 从“打开本地项目”选择已有工程；已有平台项目可从“连接本机”接入。 | 在现有项目基础上继续开发，保留自己的源码与版本管理。 |
| AI 与人工协作 | 通过共用工作台查看资源树、编辑文件、使用用户终端，并让 AI 修改本地项目文件。 | 将已有的开发习惯与 AI 协作结合起来。 |
| 检测本机工具 | 查看 Git、Node.js 及按目标需要的 Android、微信工具是否就绪，按提示补齐环境。 | 在开始目标端操作前了解工具条件与缺项。 |
| 连接原生目标端 | 按应用声明及目标环境进行构建与预览，在 Android 模拟器或微信开发者工具中操作，查看截图、状态和日志。 | 在对应目标环境中验证关键交互，并保留人工接管入口。 |

浏览器版适合直接进入在线工作台；桌面版复用同一套项目工作台，进一步连接本地工程和本机工具。客户端的登录、AI 调度与业务 API 连接所选的平台服务，可接入云端平台或企业私有化平台。在“文件 → 服务器设置”中配置服务地址，保存后按提示重新启动。

## Windows 安装版与绿色版

当前面向 **Windows x64 内部试用**，提供安装版和完整程序目录形式的绿色版。安装版通过安装向导运行；绿色版保留完整目录，直接打开其中的 `Buildploy Studio.exe`。两种形式使用相同的工作台与本机接入能力。

客户端内置自身运行所需的执行组件；Git、Node.js、Git Bash 及目标端 SDK、模拟器和微信开发者工具使用本机已有安装，按目标需要准备。

## 典型使用路径

1. 启动客户端，连接平台服务并登录。
2. 打开本地 Git 工程，或为已有项目选择“连接本机”。
3. 在本机管理窗口核对项目目录与工具检测结果，再打开工作台。
4. 结合 AI 会话、文件编辑与用户终端继续开发；按项目支持的操作构建、预览，并实际验证目标端交互。

同一项目保持明确的活动工作位置。已有云端源码的项目接入本机时，按界面流程完成交接；源码版本、备份和位置切换通过明确的 Git 操作处理。当前桌面版尚未提供自动双向源码同步与持续云端备份，登录和 AI 服务需要能够访问所连接的平台及模型服务。

桌面版是应用开发入口。需要面向企业员工交付业务应用时，可继续了解[企业级支持](enterprise.md)中的团队治理、企业工作台模板与应用独立运行能力。
