# Buildploy 使用文档

Buildploy 将 AI 协作、应用源码、业务数据、预览验证和交付连接在一个工作台。本目录面向云端服务及企业部署环境的用户，从产品全景到第一次实际构建逐步展开。

## 先了解产品

- [整体架构](architecture.md)：工作台、项目工程、资源与交付目标之间的关系。
- [功能全景](features.md)：从需求到应用，能完成哪些工作、带来什么价值。
- [核心功能 UI](showcase.md)：围绕订单运营台查看典型界面和应用成果。
- [小程序与 Android 实际预览](mobile-preview.md)：在目标端中运行应用，查看原生界面和真实交互。
- [桌面版支持](desktop.md)：Windows 工作台、本地工程与原生工具接入。
- [企业应用与 AI 协作](enterprise.md)：图解应用如何连接企业数据、业务工具与人工流程，展示销售分析和申请办理案例。
- [云端与私有化部署](enterprise.md#云端与私有化部署)：平台服务与业务应用的部署选择、网络与资源配套。
- [关于 AI Native 的理解](ai-native.md)：关于人的主导权、系统可靠性、模型替换及既有设施协作的一些思考。
