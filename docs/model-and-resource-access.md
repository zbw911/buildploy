# 模型及资源自主接入指引

本文面向在线工作台用户，说明可以自行配置的资源、配置入口，以及在构建、工作流和交付中的支持范围。

[进入工作台](https://code.buildploy.com/) · [文档目录](README.md) · [返回仓库首页](../README.md)

## 平台支持与自带资源

Buildploy 提供一定额度的模型调用支持，具体额度以开通时说明为准。对于大规模或持续的模型使用，可以接入自己的模型服务。

自带模型的调用费用由用户与模型服务商结算，不消耗平台模型额度。自行接入的数据库、API 等资源，其服务费用和账号权限由用户管理。

## 可配置资源与支持范围

| 资源 | 配置入口 | 当前支持范围 |
| --- | --- | --- |
| 模型服务 | 项目设置 → 项目 LLM | 配置接口地址、API Key、模型 ID 和能力；支持 Chat Completions、Responses 接口，用于该项目的 AI Builder 构建过程 |
| MySQL | 数据源 | 配置自有连接、测试连接、只读浏览表和数据；支持工作流及发布后服务的数据库查询、更新和事务 |
| Redis | 数据源及工作流 | 配置自有连接，供工作台内工作流调用；暂未提供通用在线连接测试，发布包尚未接入 |
| 外部 HTTP API | 工作流 HTTP 请求配置 | 在工作台内配置请求并验证返回结果，受平台访问策略约束；发布包尚未接入相同的工作流 HTTP 调用能力 |
| 微信小程序凭据 | 项目发布 → 应用发布设置 | 配置本应用的 AppID、代码上传私钥和微信登录 AppSecret，分别用于代码上传和业务登录 |
| Android 签名 | 项目发布 → 应用发布设置 | 导入本应用的签名文件及密码、别名，用于正式 APK 签名；不包含应用商店自动上架 |

其他数据库、消息队列、搜索和对象存储类型不纳入当前完整接入清单。部分类型虽然可以登记配置，实际调用、连接测试与发布后运行的支持范围仍需分别确认。

云执行器与 NAS 的后续扩展见[路线图](../README.md#路线图)，不属于当前用户自带业务资源的接入入口。

## 接入自己的模型

### 准备信息

由项目所有者准备模型服务的 HTTPS Base URL、API Key 和模型 ID。当前每个项目配置一条项目模型连接；只有项目所有者可以保存、测试、启用、停用或清空密钥。

项目 LLM 当前只接受通过地址安全校验的公网 HTTPS 地址，不支持本机或私网模型地址。

| 接口协议 | 接入要求 |
| --- | --- |
| Chat Completions | 服务提供兼容的 Chat Completions 接口，并支持实际构建任务所需的工具调用、代码生成等能力 |
| Responses | 服务提供兼容的 Responses 接口，并满足实际任务所需的能力和参数要求 |

协议兼容和模型能力需要分别确认。能够返回文本的模型，不一定满足 AI Builder 的工具调用和代码构建要求；图片等额外能力也应按实际任务确认。

### 配置步骤

1. 打开项目的“项目设置”，进入“项目 LLM”。
2. 选择与服务一致的接口协议，填写 Base URL 和 API Key。Base URL 可参考占位形式 `https://api.example.com/v1`，实际地址以服务商说明为准。
3. 点击“检测模型”后选择模型；服务未提供模型发现时，可以手动填写服务商给出的模型 ID。根据服务的真实能力核对 Capabilities。
4. 按需设置超时和 Max Tokens，点击项目设置页的保存按钮。
5. 点击“测试连接”，测试通过后点击“启用”，确认显示“项目模型生效中”。
6. 发起一次小规模构建任务，检查工具执行结果，并在“项目模型用量”中查看调用次数和 Token 用量。

API Key 保存后不会回显；留空保留已有密钥，重新输入则覆盖。密钥只在工作台对应配置入口录入。

### 生效与停用

启用项目模型后，该项目仅使用自己的模型连接，不再消耗平台模型额度；连接失效或模型不可用时会报错，不自动改用平台模型。停用项目模型后，恢复平台模型及平台额度规则；平台额度耗尽时，平台模型调用会被阻断。

项目 LLM 用于 AI Builder 构建过程。发布后应用如果需要调用模型服务，应另行配置自己的业务调用，项目 LLM 配置不会自动成为应用的业务模型配置。

## 接入业务资源

### MySQL

1. 从工作台左侧资源树新建或选择数据源，选择关系数据库和 MySQL。
2. 填写主机地址、端口、数据库名、用户名和密码，保存当前连接参数。当前数据源入口维护一套运行参数。
3. 点击“测试连接”，确认数据库连接验证通过。
4. 在数据浏览区核对表和数据，或执行只读 SQL 查询；工作台数据浏览不提供数据编辑和表结构管理。
5. 在工作流中选择该数据源执行所需操作，并在目标运行环境验证结果。发布后服务可使用已配置的 MySQL，操作范围受数据库账号权限和平台规则共同约束。

### Redis

在数据源中选择 Redis，填写主机、端口、数据库索引及所需账号信息并保存。在工作台工作流中引用该数据源，执行所需 Redis 操作并检查返回结果。

Redis 当前没有通用在线连接测试入口，需通过实际工作流调用验证。该能力目前限工作台工作流，发布包尚未接入。

### 外部 HTTP API

在工作流中配置 HTTP 请求的地址、方法、请求头及参数或请求体，先在工作台执行并核对返回状态和内容。可用地址受平台访问策略约束。

将 REST API 登记为数据源，不会自动完成工作流请求配置或证明接口可用。当前未提供 REST 数据源的通用在线连接测试；工作台 HTTP 调用能力也尚未接入发布包。

## 配置应用交付凭据

以下凭据由项目所有者在“项目发布”页管理：找到“选择发布内容”中的对应应用，点击齿轮打开“应用发布设置”。凭据正在被交付任务使用时，需等待任务结束后再修改。

### 微信小程序

1. 填写本应用的“微信 AppID”，保存应用发布设置。
2. 选择“代码上传私钥”文件，点击“保存上传私钥”，用于上传该应用的小程序代码。
3. 应用需要微信业务登录时，另外填写“微信登录 AppSecret”，点击“保存微信登录密钥”。

上传私钥与登录 AppSecret 各有用途，需要分别配置；保存凭据不表示代码已经上传或小程序已经上线。

### Android

选择“用户签名文件”，填写“密钥库密码”“密钥别名”“密钥密码”，点击“保存 Android 签名”。正式 APK 构建使用本应用的签名身份；未导入用户证书时，平台可为应用生成并持续复用默认签名。

首次导入用户签名可能改变此前默认签名的身份，旧 APK 可能无法直接覆盖安装。已使用的用户签名需要保持一致；应用商店上架由用户自行完成。

## 配置与验证中遇到问题

| 情况 | 检查方式 |
| --- | --- |
| 无法保存或启用项目模型 | 确认当前账号为项目所有者、连接已保存、API Key 已设置且测试成功 |
| 模型检测没有结果 | 核对地址与密钥；服务不支持模型发现时手动填写模型 ID，再测试连接 |
| 模型认证失败、超时或能力不足 | 核对协议、地址、密钥、服务额度和实际模型能力；不要勾选服务并未提供的能力 |
| 数据库或 API 连接失败 | 核对地址、端口、凭据、服务权限及目标执行环境的网络可达性 |
| 保存了资源配置但调用未成功 | 分别检查保存结果、真实连接或调用结果，以及工作流是否引用正确资源 |
| 工作台调用成功，发布后仍不可用 | 核对上表的发布支持范围，并在实际发布环境单独验证 |

公开反馈只提供脱敏错误和操作步骤，不提交 API Key、密码、私钥、签名文件或业务数据。反馈方式见[贡献指南](../CONTRIBUTING.md)。

具体控件名称和可用操作以当前工作台为准。
