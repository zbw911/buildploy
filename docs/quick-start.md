# 快速入门

目标：从一个范围明确的小需求开始，构建应用，并通过实际操作确认它能工作。

## 1. 进入工作台

打开 <https://code.buildploy.com/>，按页面提示完成登录，创建或打开你有权限访问的项目。若账号或访问遇到问题，可在 Issue 中说明现象，请勿公开账号凭据。

## 2. 描述一个小需求

在 AI 构建会话中说明使用者、页面、字段和关键操作。第一次建议先做一个简单页面，再逐步连接真实数据。

例如：

> 帮我做一个订单管理 Web 应用。需要订单列表，包含订单编号、客户、金额、状态。可以按状态筛选、查看详情。先用示例数据验证页面交互，不连接真实业务数据库。

如果需要其他目标端，请明确说明 Web、微信小程序或 Android，并确认当前环境具备相应能力。

## 3. 检查并调整实现

查看 AI 会话中的执行反馈和项目文件。根据实际结果补充需求，例如筛选条件、空列表提示或错误提示。遇到执行失败时，先查看具体报错，再围绕同一问题继续说明。

连接真实数据前，确认数据来源、访问权限和需要执行的读写操作，使用测试数据验证。不要将密钥粘贴到公开 Issue。

## 4. 运行预览并验证

使用项目提供的预览或验证入口，实际检查：

- 页面是否能打开，内容与布局是否符合需求。
- 筛选、详情等关键操作是否产生正确结果。
- 空数据、无匹配结果等状态是否可理解。
- 接入数据后，页面显示与实际执行结果是否一致。

AI 轮次完成或构建成功并不代表应用已经可用。Web 预览也不能替代微信或 Android 的实际运行检查。

## 5. 查看交付结果

需要交付时，在交付中心按当前项目支持的目标选择操作，并查看执行进度、错误和产物。构建产物、下载链接与可访问的线上地址是不同结果；以实际交付记录为准，不保证所有环境均已配置全部目标端能力。

## 6. 遇到问题

阅读[常见问题](faq.md)，或按[反馈指南](../CONTRIBUTING.md)提交 Issue，提供操作步骤、预期结果、实际结果和脱敏截图。
